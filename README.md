# 人教版八年级上册英语点读项目 · 工作区

围绕「单词学习站」(`words.vip.cpolar.cn`) 八上模块的资料工作区：教材原文核对、官方录音切片、单词音频对齐、挖空题生成、句子模块设计与实施记录。

> 本仓库为**轻量化**版本：只放脚本、SQL、TSV/JSON 教学数据和 Markdown 文档。
> 课本扫描页（`page_*.jpg`）、截图（`*.png`）、录音切片（`*.mp3`）等二进制资产留在本地，不入库。

## 目录概览

| 目录 / 文件 | 内容 |
|---|---|
| `vocab_pipeline/` | 词库抓取、核对、合并管线（含各册参考表） |
| `sentence_module/` | 句子模块前后端改动副本 |
| `audio_assets/`, `audio_fix/` | 官方录音切分与修复脚本（音频文件本身不入库） |
| `drill/`, `stats_fix/`, `ui_fix/`, `words_fix/` | 各轮修复的代码副本与 SQL |
| `tools/` | 通用脚本 |
| `*.tsv` | 教材句子、考点、挖空题的人工核对底稿 |
| `*.sql` | 建表、补字段、修数据的一次性脚本 |
| `HANDOFF-*.md` | 阶段性交接文档 |
| `U1_*`, `八上*`, `词库*` | 核验报告与设计说明 |

## 同步

```bash
./sync.sh                      # 自动 add + 时间戳 commit + pull --rebase + push
./sync.sh "补充 U3 挖空题"      # 自定义提交说明
```

## 音频取用优先级

1. 人教社官方录音 `pep.com.cn`
2. 国家中小学智慧教育平台 `basic.smartedu.cn`
3. 都没有时才用 TTS 合成（线上站已切换为 Edge TTS `en-GB-SoniaNeural`，语速 -5%）

## 内容录入约定

- 句子必须能在教材原句中找到，不接受「多来源一致」作为依据，只认课本扫描件/纸质教材。
- 挖空题答案必须唯一，优先挖介词、连词、固定搭配关键词。
- 保留教材英式拼写（`colourful` / `humour` / `practise`）。
