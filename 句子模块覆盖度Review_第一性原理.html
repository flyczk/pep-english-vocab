二、第一性原理推导

从平台定位出发，不做假设、只顺着因果链往下推：

推导步骤推理对平台的约束
① 用户是谁 中学生。第一目标是考试得分，第二目标是能力与语感。不为"学英语"而学，为"提分 + 会用"而学。 一切功能要能指回某类考题或某种输出，否则是玩具不是工具。
② 考试考什么 听力 / 语法选择 / 完形 / 阅读 / 任务型或完成句子 / 写作。其中语篇类（完形+阅读）和写作合计占分最高，且都要求"整句整段的理解与产出"。 平台必须提供成篇的语料，而不只是孤立语法例句。
③ 素材从哪来 中考命题与教材同源同题材。教材语篇就是中考阅读/完形的"缩小版"，教材 3a–3c 就是写作任务的范文。 教材原句是最权威、最对齐考试的素材源，且已带中文翻译与朗读。
④ 平台独特优势 教材原文 + 逐句中译 + 逐句点读（TTS 代理，不依赖本地音频）+ 记忆曲线 + 挖空判分。任何教材句子都能零成本点读，收录新句子没有音频门槛。 覆盖面只受"录入工作量"限制，不受技术限制——所以缺口纯粹是投入问题。
⑤ 反推：不该做什么 若把教材全部句子无差别收进来（含 Project 说明、Vocabulary in Use 填空、Reading Plus 全文），句库会稀释成"电子课本"，必背句失焦、复习负担爆炸。 必须分层收录：按"考试用途 + 可背诵性"筛选，而非按板块全收。
结论：平台缺的不是句子，是"按考试用途分层的语篇层"。现有 136 句解决了"语法骨架"（L1）和部分"对话语境"（L2），但"阅读语篇"（L3）只有 1/8，"写作范本"（L4）为 0。

四、动手前必须先解决的 3 个架构问题

1. 句子上要有「体裁」标签（不做会乱）

现在 136 句靠自由文本 source 区分来源，统计要用 LIKE 匹配。句库到 400+ 后必须结构化，否则"按用途取句子"（如"我要写作范本"）根本无法实现。建议新增字段：

字段取值用途
genregrammar / dialogue / post / diary / narrative / speech决定句子出现在哪个入口：写作素材页只取 post/speech，听力页只取 dialogue
section_codeGF-3a / A-1b / A-2a / B-1b / B-3a替代自由文本 source，可精确统计板块覆盖度
tiercore / extendedcore = 必背（进记忆曲线），extended = 选读（只点读，不进复习队列）
为什么 tier 必须有：记忆曲线对 136 句可行，对 400 句会让"待复习"堆到几百条，孩子打开生字本就被吓退。必须区分"必背核心句"和"选读扩展句"，否则功能越多体验越差。

2. 解锁口径不能动

现行"已学范围 = 练到过的最远单元及之前"在句库翻倍后更重要：一次解锁几百句会直接压垮孩子。补数据时保持这个口径不变，让句子跟着学习进度逐步释放。

3. 内容呈现要注意的两点

① U1 的 Section B 1b 是莫斯科假期日记，含二战/反纳粹的博物馆内容（教材原文），收录无问题，但属客观历史陈述，不要挑这类句子当例句或考题。
② 英式拼写（colourful / practise / humour）沿用教材词汇表主词条，录入时统一，别改美式。

五、我的建议

先做 P0 的第一项：Section B 1b 补全，从 Unit 1 开始。
理由：① 与 U3 已上线验证过的模式完全同构，风险最低、可复用脚本；② 直接补上"阅读语篇"这个最大缺口；③ U1 的日记体是后续 U2/U4/U5/U7 各种体裁的样板，先啃下体裁最特殊的一个。

紧接着做 Section B 3a–3c 写作范本，那是平台现在 0 覆盖、对中考提分最直接的一块，做出来就是这个平台相对"只有单词和语法例句"的同类产品的真正差异点。

要不要我现在开始录 Unit 1 的 Section B 1b（日记体，约 20 句）？按既定流程：我录 → 独立复核会话核对原文 → 线上实测 → 再推进下一个单元。
